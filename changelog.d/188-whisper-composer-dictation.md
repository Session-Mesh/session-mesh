- **Dictate into the composer, with automatic sending available only by explicit opt-in.**
  Transcripts remain editable by default. Automatic sending can execute commands in an inactive
  session and applies only to new recordings made while enabled. Draft recovery retains the
  original session binding, asks before replacing saved text, and never automatically retries
  uncertain input. See [Voice dictation](docs/features.md#voice-dictation).
