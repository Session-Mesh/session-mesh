- **Extra launch options per agent.** "New session" has an Options field for every agent preset;
  tick "Make this the default" to keep it, or edit every agent in "Configuration". The options are
  added to each new launch of that agent, including a session an agent asks for, whose confirmation
  names them. Arguments that remove the agent's approvals and sandbox, or that pick a conversation,
  are refused. See [Extra options per agent](docs/operations.md#extra-options-per-agent).
