- **The device in use takes the terminal size by itself.** When several browsers show one
  session, a click, a tap or a key in a terminal takes the size for that device, with no banner;
  so do its focus or its page shown again, but only while its window has the focus and right after
  a person's action on that page. A device that only stays
  open, or is resized, takes nothing, so two devices do not fight. The banner "Terminal sized by
  another device" and its button remain as an opt-in: Configuration, Terminal, "Terminal size with
  several devices", per browser. See [Working in a terminal](docs/features.md#working-in-a-terminal).
