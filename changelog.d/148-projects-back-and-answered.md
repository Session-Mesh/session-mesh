- **The Projects view has a way back inside a project, and an answered question stops showing as
  open everywhere at once.** The task sheet's button names the tab it returns to, and `Esc` and the
  browser's Back (a phone's back gesture) go up one level: sheet, tab, first screen. An answer
  given in the Projects view leaves the sessions' "? n" markers and the Projects count at once,
  instead of after leaving Projects or the next minute's read. See
  [The Projects view](docs/features.md#the-projects-view-and-the-project-tracker).
